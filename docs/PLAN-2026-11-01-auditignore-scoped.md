# 方案：`.auditignore` 细粒度豁免（路径 : 规则）+ 注释内命中治理

日期：2026-11-01　状态：已实施（2.14.0）

## 目标

1. `.auditignore` 支持只豁免指定规则，其余规则照常审；
2. 豁免从「静默丢弃」改为「已确认豁免」可见通道（不扣分、单列一节、带理由）；
3. 修掉「注释里的示例文字被当成真实代码」这一类纯误报。

## 设计要点

- 语法：`路径 : 规则[,规则]  # 理由`；规则段必须形如 `slot/rule`（允许 `*`），
  否则整行按文件模式处理——`C:\Users`、`https://`、`a:b` 这类旧内容不会被误解析。
- 采集期：细粒度行**不参与**「整文件跳过」（写出只含整文件条目的临时 excludesFile），
  否则文件整体被跳过，细粒度退化成整文件豁免。
- 判定期：finding 产出后匹配细粒度规则 ⇒ `exempted: true`（**标记而非删除**），
  `summarize` / 维度计数 / 命中文件数 / 规则包统计全部跳过它。
- 报告期：`exemptStats.applied` 按规则分组，报告单列「已确认豁免 N 条（不扣分）」。
- 注释内命中：所有正则规则默认丢弃落在注释里的命中（注释类规则如
  `comment/*`、`documentation/*`、`comment-density`、`no-date-in-comment` 除外）；
  **只剔注释、不剔字符串**——paths/凭据类规则的命中本就写在字符串字面量里。
  候选行必须给全部行：`makeCodeLineFilter` 的 `isCode` 只对传入候选行成立，
  复用规则自身候选会把「代码里的真实命中」误判成注释内（实测硬编码密码 blocker 消失）。

## 验证

- `test/test-auditignore-rules.mjs`（9 例）：解析/歧义保护/拆分/通配匹配/标记语义/统计跳过；
- 注入自证：把 `exempted` 判定去掉 ⇒ 用例转红；
- 真实自证：本仓库 `lib/score/index.js` 从整文件豁免改为细粒度后，
  7 条（魔数/冗长函数）标记已确认豁免，另 3 条（日期注释 ×2、圈复杂度）**重新可见**；
- 全量回归 0 失败。

## 边界

- 不做跨文件数据流分析（跨文件看门狗这类仍靠细粒度豁免 + 理由说明）；
- `dsh-skip-*` 标记语义保持不变（静默丢弃），避免全仓评分大范围漂移。
