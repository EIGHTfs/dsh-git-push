## 三、风险与边界

| 风险 | 可能性 | 影响 | 缓解 |
|---|---|---|---|
| 装包执行 postinstall 任意代码 | 高 | 宿主被入侵 | 默认 `--ignore-scripts`（UI 可显式关闭并二次确认）、只允许 registry 来源、留痕、默认不全局 |
| 全局安装污染宿主环境 | 中 | 影响其它项目 | 必须显式勾选 + 二次确认 + 展示目标路径 |
| npm token 明文泄露 | 中 | token 被盗 | 0600 落凭据目录、UI 只回显脱敏、绝不进 config.json 明文 / 仓库 |
| registry 慢或不可达 | 中 | 页面卡住 | 8s 短超时 + 降级手输包名 + 可读错误 |
| client.js 可能是构建产物 | 中 | 手改被覆盖 | Step 0 先核实构建链，只改源分片，改后跑 `build-client.mjs` |
| 破坏既有账号 UI | 中 | 仓库管理卡失灵 | 只加标签与卡片、不动既有逻辑 + 回归断言 |
| 并发安装同一包 | 低 | 状态错乱 | 端点级「安装中」锁 + 明确回执 |

边界：未登录/无 token ⇒ 显示「未配置」+ 设置入口；registry 超时/404 ⇒ 降级；目录无写权限/非项目目录 ⇒ 前置校验；目录无 package.json ⇒ 询问 init 还是仅装依赖；包名非法 ⇒ 前置校验；输出超长 ⇒ 截断 + 落日志。
